# 官方资料与经典论文

## 使用方式

先完成对应章节的最小实验，再带着具体问题读资料。论文解释思想和实验环境，不等于可直接复制的生产架构；框架文档说明 API，不替代业务权限与评测设计。

## 第一层：概念主线

### ReAct

[ReAct: Synergizing Reasoning and Acting in Language Models](https://arxiv.org/abs/2210.03629)

关注：推理与外部行动交替的基本模式。阅读时对照 [[02-核心机制/07-Agent Loop]]，思考生产 Runtime 为什么还需要校验、预算和权限。

### RAG

[Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks](https://arxiv.org/abs/2005.11401)

关注：参数知识与外部非参数知识结合的动机。工程实现还需要 [[02-核心机制/05-RAG]] 中的文档版本、ACL、引用和分阶段评测。

### Long Context

[Lost in the Middle: How Language Models Use Long Contexts](https://arxiv.org/abs/2307.03172)

关注：信息位置会影响长上下文利用效果。它能帮助理解为什么 [[03-工程实践/Context Engineering]] 不是简单把更多内容放进窗口。

## 第三层：评测与生产基本功

### 指标与统计

- [scikit-learn：F1 的定义](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.f1_score.html)：核对 TP、FP、FN 与分母；库的零分母默认行为需与项目统计约定一致。
- [R：样本分位数的不同算法](https://www.stat.ethz.ch/R-manual/R-devel/library/stats/html/quantile.html)：对照 type 1 理解 nearest-rank，再看为什么插值算法可能给出不同 P95。
- [NIST：比例的 Wilson 置信区间](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)：理解小样本成功率的不确定性，不必先推导所有公式。

配套笔记：[[06-评测安全生产/评测指标怎么算]]、[[06-评测安全生产/评测数据集设计]]。链接与相应定义核对日期：2026-09-05。

### 身份与委托授权

- [OpenID Connect Core 1.0](https://openid.net/specs/openid-connect-core-1_0.html)：关注身份认证、ID token 与校验责任。
- [RFC 9700：OAuth 2.0 Security Best Current Practice](https://www.rfc-editor.org/rfc/rfc9700)：结合成熟认证库理解授权码、令牌泄露与受众限制。
- MCP 的逐跳授权参见上面的版本化 Authorization 规范，不把第一跳 token 直接透传到下游服务。

配套笔记：[[03-工程实践/身份、凭据与委托授权]]。新增 OIDC、OAuth 来源核对日期：2026-09-05；MCP 版本基线沿用第二层记录。

### 异步执行与服务目标

- [RFC 9110：202 Accepted](https://www.rfc-editor.org/rfc/rfc9110.html#name-202-accepted)：HTTP 202 表示已受理处理请求，不承诺任务已经完成。
- [Google SRE：Service Level Objectives](https://sre.google/sre-book/service-level-objectives/)：用具体服务区分 SLI、SLO 和 SLA，并理解延迟分布与统计窗口。

配套笔记：[[03-工程实践/异步任务与取消]]、[[06-评测安全生产/可观测性与生产化]]。核对日期：2026-09-05。HTTP 状态码只说明协议语义；教程中的 job 状态、取消和 lease 仍需按所接系统的契约实现。
