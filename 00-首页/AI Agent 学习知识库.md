## 当前实践路线

1. [[05-项目实战/01-Minimal Chatbot|Minimal Chatbot]]：理解模型 API 和结构化输出。
2. [[05-项目实战/02-Mini Agent CLI|Mini Agent CLI]]：实现工具调用与 Agent Loop。
3. [[05-项目实战/03-RAG 知识助手|RAG 知识助手]]：实现检索、引用和评测。
4. [[05-项目实战/04-客服工单 Agent|客服工单 Agent]]：整合状态、审批、评测和生产化边界。

每个项目分“基础通过 / 标准完成 / 生产加餐”。先交付一个小闭环；标准版再扩充样本与失败分支。入门工单项目统一使用 [[01-基础/02-Prompt 与结构化输出#工单分类契约]]，不要把不同业务抽取示例误作同一套标签。

项目 3 完成基础版后，可选做 [[labs/02-llm-wiki/README|LLM Wiki 最小练习]]：把来源整理成页面，保留证据和版本，再验证更新、冲突与来源撤回。不新增第五个主项目。

## 使用约定

- 一个笔记只解决一个核心问题，标题尽量可直接搜索。
- 概念笔记写“定义、机制、边界、例子、检查题”，不要只收藏链接。
- 每完成一章，在 [[08-学习记录/学习看板]] 更新状态，并写一篇实验记录。
- 标签用于状态和类型，双向链接用于知识关系。
