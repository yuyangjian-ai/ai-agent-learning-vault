# AI Agent 学习路线

## 学习原则

每个阶段都按四步完成：**理解概念 → 做最小实验 → 记录失败 → 用验收题自测**。不要只阅读，也不要一开始就堆框架。

开始第 1 周前先看 [[00-首页/从这里开始]]，准备环境并浏览 [[00-首页/贯穿案例：重复扣款工单]]。第一次只看主流程；学到 Tool、RAG、状态和评测时，再回来定位每个组件的职责。

这是学习顺序，不是交付工期承诺。每周优先达到项目的“基础通过”；有余力再完成标准版，生产加餐按需延伸。安全与权限也不是等到第 7 周才加：一旦接触真实数据、凭据或外部写操作，就要先具备对应保护。

语言主线为 Node.js + TypeScript，也可全程用 Java。读 [[03-工程实践/TypeScript 与 Java 实现对照]]，将 Runtime、Gateway、State 映射到熟悉的 Service、适配器和数据库状态；不要把“学习 Agent”变成“先换一门语言”。

## 三个里程碑

### 里程碑 A：模型应用

- [ ] 能解释 token、上下文窗口、temperature 和幻觉。
- [ ] 能使用 schema 得到结构化结果，并处理解析失败。
- [ ] 能记录模型、提示词、参数、耗时和成本。

### 里程碑 B：可控 Agent

- [ ] 能实现“模型决策 → 工具执行 → 结果回填 → 再决策”。
- [ ] 工具有明确 schema、超时、权限和错误语义。
- [ ] 循环有最大步数、取消、人工确认和完整轨迹。

### 里程碑 C：具备上线评审材料

- [ ] 有离线评测集，能比较版本效果。
- [ ] 能抵御提示注入、越权工具调用和敏感信息泄露。
- [ ] 能追踪每次运行的质量、延迟、成本和失败原因。

达到这些学习验收项不等于已经获得生产上线许可；真实上线还需要实际数据评估、安全审查、运营责任与回滚演练。

## 每周节奏

- 40%：读核心笔记并用自己的话复述。
- 40%：写最小可运行实验。
- 20%：复盘、补链接、更新评测样本。

如果时间有限，优先完成每周“必须产出”，不要为了看完所有资料而推迟实践。

## 每周详细学习任务

### 第 1 周：理解模型而不是背术语

- 阅读 [[01-基础/01-LLM 基础]]，完成参数和幻觉练习。
- 阅读 [[01-基础/02-Prompt 与结构化输出]]，理解共用工单分类 schema，先不改标签。
- 用 [[05-项目实战/01-Minimal Chatbot]] 做基础版 V0/V1：先处理 10 个固定 mock 响应，验证状态与校验流程；这不算真实模型验收。
- 验收：能区分模型知识、上下文推断和外部行动。

### 第 2 周：把一次调用做可靠

- 学习 [[01-基础/03-模型 API 与消息协议]] 的流式、超时和重试。
- 学习 [[03-工程实践/Context Engineering]]，实现 context manifest。
- 完成 Chatbot V2/V3；标准版固定 20 条输入，每条重复 3 次，共 60 次运行。数据契约和门禁以项目页为准。
- 按 [[06-评测安全生产/评测指标怎么算]] 手算结构通过率与端到端成功率，保留失败分母。
- 验收：任意失败都能归类，能重放一次调用。

### 第 3 周：工具与权限

- 精读 [[02-核心机制/04-Tool Calling]] 和 [[03-工程实践/Tool 设计]]。
- 跑 [离线 Runtime 实验](../labs/01-agent-runtime/README.md)，观察成功、越权和超时三个场景；此时不要求写全循环。
- 接真实系统前阅读 [[03-工程实践/身份、凭据与委托授权]]，区分用户身份与工具服务凭据。
- 实现 Mini Agent CLI M1/M2。
- 做路径逃逸、参数错误、工具超时测试。
- 验收：能解释“模型决定调用”和“系统授权执行”的区别。

### 第 4 周：Runtime

- 学习 [[02-核心机制/07-Agent Loop]]、[[03-工程实践/状态、事件与持久化]]。
- 浏览 [[03-工程实践/Agent 系统架构]]，画出本项目一次请求的端到端路径。
- 选读 [[03-工程实践/Human-in-the-loop]]，为后续受控写操作画出暂停与恢复点。
- 加入 [[03-工程实践/错误恢复与幂等]] 的超时恢复与重复动作测试；若实现 M5，再验证写入幂等。
- 实现 CLI M3/M4，加入上下文控制与循环检测；标准版完成后，再按生产加餐演练 checkpoint 恢复，不要求基础版就持久化长任务。
- 涉及慢工具时选读 [[03-工程实践/异步任务与取消]]，区分 run 结束与外部任务实际结果。
- 验收：能从 trace 解释恢复行为，并说明 checkpoint 与幂等的边界；达到预算会安全停止。

### 第 5 周：知识与记忆

- 学习 [[01-基础/04-Embedding 与向量检索]]、[[02-核心机制/05-RAG]]、[[02-核心机制/06-Memory]]。
- 先用 6 篇文档、10 道题完成 RAG 基础版，再做 E1–E4；标准版用 25 道固定题（20 道可答、5 道无答案）。
- 验收：能分别定位 retrieval failure 和 generation failure。

### 第 6 周：复杂编排

- 学习 [[03-工程实践/Workflow 与 Agent]]、[[02-核心机制/08-Planning 与 Reflection]]、[[02-核心机制/09-Multi-Agent]]。
- 用同一任务比较固定 Workflow、单 Agent 和并行 Workers。
- 验收：能用数据说明复杂架构是否值得。

### 第 7 周：证明可靠

- 设计 [[06-评测安全生产/评测数据集设计]]。
- 复核 [[06-评测安全生产/评测指标怎么算]] 中 Recall@k、引用支持率、P95 和样本量的分母。
- 完成 [[06-评测安全生产/Prompt Injection 攻防]] 和权限攻击测试。
- 验收：发布门禁包含质量、轨迹、安全、延迟和成本。

### 第 8 周起：综合上线演练

- 启动 [[05-项目实战/04-客服工单 Agent]] 的 12 条合成工单基础版，后续逐步扩展标准版；获授权后的真实影子运行属于生产加餐，不是第一周综合项目的前置条件。
- 接入 [[06-评测安全生产/可观测性与生产化]]。
- 使用 [[03-工程实践/模型网关与路由]] 锁定模型版本与降级策略。
- 使用 [[06-评测安全生产/成本与性能]] 做一次优化实验。
- 验收：能提交 evidence pack，并清楚说明已知限制。

## 主线之后的按需拓展

- 用图片、音频或网页界面完成任务：[[04-框架与生态/多模态与 Computer Use]]。
- 深化真实身份与跨系统权限：[[03-工程实践/身份、凭据与委托授权]]。
- 处理分钟级任务、回调与用户中途改意图：[[03-工程实践/异步任务与取消]]。
- 卡在术语或不知道该改哪层：[[07-术语与资源/常见困惑与排错]]。
